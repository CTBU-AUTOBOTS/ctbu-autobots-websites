# 【通知公告】逐梦启航，聚力同行——第九届汽车人协会顺利开展招新面试工作

为充实协会骨干力量，完善组织架构，为社团发展注入新鲜血液，进一步推动协会文化建设，2026年10月23日下午，我校第九届汽车人协会顺利开展新一届部长及干事招新面试工作。本次面试由协会指导老师张威，协会四位会长共同参与面试评审，分工协作、严格筛选，保障面试工作有序、高效、公正开展。

本次面试分为部门部长面试与新生干事面试两个阶段有序进行。面试过程中，评审团队结合汽车人协会各部门的工作职能、岗位需求，针对性地对参选同学的个人特长、工作认知、责任意识、时间规划能力以及未来工作规划等方面进行全面考察。同时，耐心解答同学们关于部门工作内容、社团发展方向的疑问，深入了解每一位参选同学的综合能力。

参选的同学们精神饱满、态度端正，从容自信地展示自我。大家结合自身兴趣与技能优势，阐述了自己加入协会的初心、对岗位的理解，以及未来履职的工作设想，充分展现出参选同学积极进取、勇于担当的青春风貌。

经过严谨的面试评审，**第九届汽车人协会部长**录用名单正式确定，具体如下：

|    部门    | 姓名                             |
| :--------: | :------------------------------- |
| 宣传策划部 | 罗崟、彭艳、冉巧奇、袁浩桓、周豪 |
|   技术部   | 高春雨、万品航、刘波             |

**干事**面试选拔结果如下：

|    部门    | 姓名                                                 |
| :--------: | :--------------------------------------------------- |
| 宣传策划部 | 陈少飞、梁渝林、刘瑾、李秀豪、时东旭、熊林锋、邹恺鑫 |
|   技术部   | 暂无                                                 |

> 据悉，汽车人协会技术部专业性、实操性较强，对成员的专业技能、动手能力有着更高的标准与要求。为择优筛选优质人才，打造专业硬核的技术团队，技术部后续将开展专项技能考核，因此本次面试暂不确定干事名单，最终干事录用结果将在考核结束后另行公示。

此次招新面试工作的圆满完成，为汽车人协会搭建了全新的骨干团队架构，吸纳了大批有热情、有能力的新鲜力量。相信在指导老师的协助、新一届干部与干事的共同努力下，汽车人协会将凝心聚力、笃行奋进，持续开展特色社团活动，深耕汽车专业文化，在丰富校园课余文化生活、帮助同学们锻炼专业实践能力的道路上稳步前行，书写社团发展的崭新篇章！
